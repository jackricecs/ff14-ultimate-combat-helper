# 03 资源 / 充能溢出监控（规划中，v0.3）

## 目标
1. **战斗中**：资源即将溢出时提醒（可选，默认关，避免干扰）。
2. **战后报告**：本次战斗中哪些资源/技能充能溢出了多少、发生在什么时间点（尤其是开场爆发后），写入界面并可选播报摘要。

## 两类"溢出"，难度不同
| 类别 | 例子 | 数据来源 | 难度 |
|---|---|---|---|
| 技能充能/冷却空转 | 双充能技能满充能后未用、120 秒团辅好了却晚放 | `21/22` 自己的技能使用时间 + 技能复唱表 | 低：只需维护"技能 ID → 复唱/充能数"表 |
| 职业量谱资源溢出 | 黑魔通晓层数满时再获得、诗人灵魂之声满 100、忍者忍气满 | `31 NetworkGauge`（原始字节，需按职业解码） | 中–高：每个职业一套解码，且随版本改动 |

建议先做第一类（通用、稳定），再逐职业做第二类，从黑魔开始。

## 设计草案
- `CooldownTable`：技能 ID → { 复唱秒数, 最大充能, 是否受技能速度影响 }。来源：手工维护 + 可选从 xivapi / 游戏数据表生成（脚本放 `tools/`）。
- `ResourceModule : IModule`：
  - `OnLogLine(21/22)`：记录自己的技能使用，推进每个技能的充能状态机；满充能后开始累计"空转秒数"。
  - `OnLogLine(31)`：交给 `IGaugeDecoder`（按职业注册）解析当前资源值；检测"已满时又有获取事件"。
  - 战斗结束（ACT `InCombat` 由真变假）：生成 `OvercapReport`（技能/资源、次数、累计浪费、首次发生时间）。
- 开场爆发窗口：默认取战斗开始后 0–25 秒，可配置；报告中单独列出该窗口内的溢出。

## 待验证问题
- 国服 `31` 行字节布局是否与国际服同版本一致（预期一致，需实测）。
- 技能速度对复唱的影响：可从 `Player.SkillSpeed/SpellSpeed` 推算，或先只做不受速度影响的能力技。
